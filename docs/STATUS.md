# Status entry point

This file is the fixed cross-PC status entry point.

## Canonical handoff

The authoritative current implementation handoff is:

- `docs/PROGRESS.md`

Read it before implementation and update it before ending a meaningful Codex session.

## Required handoff fields

The latest handoff must include:

- active branch;
- completed work;
- next/remaining work;
- verification performed;
- blockers and external dependencies.

Do not duplicate the complete progress log here. This file exists so every machine and Codex session can find the same handoff immediately.
